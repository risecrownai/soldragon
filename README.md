# 연꽃 · 용 · 태양 불경 사이트

원문 + 영어 번역을 보여주고 자동 낭독하는 웹사이트입니다. 빌드 과정이 없고, 화면 파일은 `public/`에 있습니다. **Cloudflare Workers + D1**에 배포하면 로그인·클라우드 저장·좋아요/점수/댓글이 켜지고, 설정이 없으면(Netlify/Vercel 등 정적 호스팅) 예전처럼 브라우저 저장만 쓰는 모드로 동작합니다.

- **낭독**: 브라우저 Web Speech API. 보기·낭독 언어를 `원문+영어+한국어 / 원문 / 영어 / 한국어` 중에서 고르면 선택한 언어만 표시되고 낭독됩니다. `원문 + 영어 + 한국어`는 세 언어를 모두 보여 주되 원문만 낭독합니다. 각 문단의 `▶ 여기서부터` 버튼으로 원하는 부분부터 낭독을 시작할 수 있습니다. 볼륨(기억됨)과 속도를 조절할 수 있고, 경전을 클릭하면 자동 낭독됩니다.
- **음성 선택 / 음높이**: `음성 선택`에서 이 기기에 설치된 음성 중 이름으로 남성/여성이 구분되는 것만 `남성 · 이름` / `여성 · 이름`으로 보여 줍니다(구분할 수 없는 음성은 숨기고, 고를 음성이 없으면 메뉴 자체가 사라져 기기 기본 음성으로 읽습니다). 선택은 언어별로 기억됩니다. `음높이` 슬라이더(0.6–1.4)로 소리의 높낮이를 조절합니다.
- **일시정지 / 반복**: `⏸ 일시정지`로 멈췄다가 `▶ 계속`으로 이어 읽습니다. 반복 횟수(1·3·5·7·10·21·108·무한)와 반복 단위(경전 전체 / 문단별)를 고를 수 있습니다.
- **경전 순서**: 왼쪽 메뉴의 `⇅ 순서 변경`에서 경전을 선택한 뒤 `맨 위 / 위로 / 아래로 / 맨 아래` 버튼(또는 ↑ ↓ 키)으로 옮깁니다. 순서는 브라우저에 저장되며 `초기화`로 원래 순서로 돌아갑니다.
- **경전 추가·수정·삭제**: 왼쪽 메뉴의 `＋ 경전 추가`, 직접 추가한 경전의 `✎`(수정)·`✕`(삭제). 원문·영어·한국어는 같은 순서로 빈 줄로 문단을 구분합니다(번역이 없는 문단은 `-` 한 줄). **암호화폐 지갑을 연결했을 때만** 추가·수정·삭제·가져오기가 가능합니다(화면 잠금일 뿐 서버 인증은 아니며, 데이터는 이 브라우저의 localStorage에만 저장됩니다). `내보내기`는 내보낼 경전을 골라 JSON으로 저장합니다.
- **클라우드 모드 (Cloudflare Workers + D1)**: 기본 경전 7개는 코드(`public/sutras.js`)에 있고, 사용자가 추가한 경전만 D1에 저장됩니다. **지갑 서명으로 로그인**합니다(상단 `로그인` → 지갑 연결 → `서명하고 로그인`; 거래·수수료 없음, 서버가 Ed25519 서명을 검증하고 지갑 주소가 곧 계정이며 이메일 등은 수집하지 않음). 로그인하면 경전을 추가·수정·삭제할 수 있고, 경전마다 `🔒 비공개`(나만) / `🌐 공개`(누구나 읽기)를 고릅니다. 공개 경전과 기본 경전에는 로그인한 사람이 `좋아요/싫어요`, 점수(★1~5), 댓글(100자 이내)을 남길 수 있습니다(비로그인은 읽기만). 이 브라우저에만 있던 경전은 ☁ 버튼으로 클라우드(비공개)로 옮기고, 가져오기 파일도 비공개로 올라갑니다. 권한 검사는 모두 서버(`src/api.js`)에서 하며, 웹 대시보드만으로 배포하는 방법은 [docs/CLOUDFLARE.md](docs/CLOUDFLARE.md)를 보세요.
- **화면 언어**: 상단의 언어 선택으로 전체 메뉴를 한국어/English로 전환합니다(선택은 기억됨, 처음에는 브라우저 언어를 따름). 문구는 `public/i18n.js`에서 수정합니다.
- **이미지**: `public/images/` 의 부처님·비로자나불·관세음보살·연꽃·태양, ·용 SVG 2종(`dragon.svg` 귀여운 용: 홈 화면·천수경·기본 그림, `dragon-pearl.svg` 다리가 있고 여의주를 문 용: 금강경·불정존승다라니경·사이드바). 화면 상단의 태양 그림(헤더 로고와 경전 상단의 태양)을 누르면 홈 화면으로 돌아갑니다. 경전 낭독 화면의 상단 그림은 경전마다 `public/sutras.js`의 `hero`(그림 3개)와 `heroTheme`(배경색)로 지정합니다.
- **솔라나 지갑**: **Jupiter, MetaMask, Solflare** 3개만 지원합니다(Wallet Standard 방식). 지갑 선택 창에서 고르면 연결되고, 상단에 주소와 SOL 잔액(Mainnet/Devnet)이 표시됩니다. 연결 실패 시 거절/실패 원인이 창 안에 표시되고 다른 지갑으로 다시 시도할 수 있습니다. MetaMask는 공식 SDK(`public/vendor/metamask-solana.js`, 지갑 창을 처음 열 때 불러옴)로 연결합니다. 연결이 실패하면 지갑 창에 거절/실패 원인과 `진단 정보`(복사 가능)가 표시됩니다. 지갑 창은 모달이 아니라 일반 창이라 MetaMask SDK가 띄우는 안내창을 누를 수 있습니다.
- **스마트폰**: 폰 브라우저에는 확장 프로그램이 없으므로 MetaMask는 지갑 선택 창에서 바로 연결하거나, `MetaMask 앱에서 열기`·`Solflare 앱에서 열기`(앱 내장 브라우저)로 엽니다.
- 기본 경전: 반야심경, 금강경(발췌), 금강경 사구게, 불정존승다라니경(다라니·요약), 천수경(발췌), 법구경, 자애경. 금강경·불정존승다라니경·천수경은 전문이 아닌 발췌이며 번역은 직접 작성한 것이므로 사용 전 검수하세요.
- 기본 경전은 `public/sutras.js` 에서 수정할 수 있습니다.

## Cloudflare Workers + D1 배포 (권장, 무료)
로그인·클라우드 저장·좋아요/점수/댓글을 쓰려면 이 방법입니다. 단계별 안내: **[docs/CLOUDFLARE.md](docs/CLOUDFLARE.md)**

## Netlify 배포 (무료, 클라우드 기능 없음)
1. Netlify → *Add new site → Import from Git* 에서 이 저장소 선택
2. Build command 비움, Publish directory `public` (netlify.toml에 이미 설정됨)
3. 배포 완료

## Vercel 배포 (선택)
1. https://vercel.com 에서 GitHub로 가입한 뒤 *Add New → Project* 에서 이 저장소를 Import
2. Framework Preset은 **Other**, Build Command와 Install Command는 비워 둠 (출력 폴더와 보안 헤더는 `vercel.json`에 이미 설정됨)
3. *Deploy* → `main`에 머지할 때마다 자동 배포되고 PR마다 미리보기 주소가 생깁니다.
- 무료 Hobby 플랜은 개인·비상업적 용도로 제한될 수 있으니 약관을 확인하세요.
- 직접 추가한 경전은 접속 주소마다 따로 저장됩니다(Netlify와 Vercel 주소가 다르면 서로 보이지 않음).

## 참고
- 팔리어는 대부분의 기기에 전용 음성이 없어 힌디어(hi-IN) 음성으로 대체 낭독합니다. 한문은 zh-CN 음성이 필요합니다.
- 페이지를 처음 열 때는 브라우저 정책상 소리가 자동 재생되지 않고, 경전을 한 번 클릭하면 재생됩니다.
- 추가한 경전은 기기·브라우저별로 저장되므로 백업은 `내보내기`를 사용하세요.

## 개발 / 테스트
- 단위 테스트: `node --test tests/unit.test.mjs` (Node 20+)
- 로컬 실행(전체 기능): `.dev.vars`에 `SESSION_SECRET=`(32자 이상)을 적은 뒤 `npx wrangler d1 migrations apply soldragon --local` → `npx wrangler dev --port 8788` → 다른 터미널에서 `node tests/integration.mjs`
