# 연꽃 · 용 · 태양 불경 사이트

원문 + 영어 번역을 보여주고 자동 낭독하는 정적 웹사이트입니다. 빌드 과정이 없습니다.

- **낭독**: 브라우저 Web Speech API. 보기·낭독 언어를 `원문+영어+한국어 / 원문 / 영어 / 한국어` 중에서 고르면 선택한 언어만 표시되고 낭독됩니다. `원문 + 영어 + 한국어`는 세 언어를 모두 보여 주되 원문만 낭독합니다. 각 문단의 `▶ 여기서부터` 버튼으로 원하는 부분부터 낭독을 시작할 수 있습니다. 볼륨(기억됨)과 속도를 조절할 수 있고, 경전을 클릭하면 자동 낭독됩니다.
- **목소리**: `기본 / 여성 / 남성`. 브라우저가 성별을 알려 주지 않아 음성 이름(SunHi, Zira, Yuna 등)으로 추정하며, 기기에 해당 음성이 없으면 음높이로 근사하고 안내 문구를 보여 줍니다. 선택은 기억됩니다.
- **일시정지 / 반복**: `⏸ 일시정지`로 멈췄다가 `▶ 계속`으로 이어 읽습니다. 반복 횟수(1·3·5·7·10·21·108·무한)와 반복 단위(경전 전체 / 문단별)를 고를 수 있습니다.
- **경전 순서**: 왼쪽 메뉴의 `⇅ 순서 변경`에서 ▲▼로 순서를 바꾸면 브라우저에 저장됩니다(`초기화`로 원래 순서 복귀).
- **경전 추가**: 왼쪽 메뉴의 `＋ 경전 추가` (원문·영어·한국어를 같은 순서로, 빈 줄로 문단 구분). 브라우저 localStorage에 저장되며 JSON 내보내기/가져오기를 지원합니다.
- **화면 언어**: 상단의 언어 선택으로 전체 메뉴를 한국어/English로 전환합니다(선택은 기억됨, 처음에는 브라우저 언어를 따름). 문구는 `i18n.js`에서 수정합니다.
- **이미지**: `images/` 의 연꽃·용·태양 SVG.
- **솔라나 지갑**: 솔라나 표준(Wallet Standard)을 따르는 지갑(Phantom, Solflare, Backpack, Jupiter, MetaMask 등)이 자동으로 선택 목록에 나타납니다. 주소와 SOL 잔액 표시(Mainnet/Devnet).
- **스마트폰**: 폰 브라우저에는 확장 프로그램이 없으므로, 지갑 선택 창의 `앱에서 열기`(Phantom, Solflare, MetaMask)로 지갑 앱의 내장 브라우저에서 이 사이트를 열면 자동 연결됩니다.
- 기본 경전: 반야심경, 금강경(발췌), 금강경 사구게, 불정존승다라니경(다라니·요약), 천수경(발췌), 법구경, 자애경. 금강경·불정존승다라니경·천수경은 전문이 아닌 발췌이며 번역은 직접 작성한 것이므로 사용 전 검수하세요.
- 기본 경전은 `sutras.js` 에서 수정할 수 있습니다.

## Netlify 배포 (무료)
1. Netlify → *Add new site → Import from Git* 에서 이 저장소 선택
2. Build command 비움, Publish directory `.` (netlify.toml에 이미 설정됨)
3. 배포 완료

## 참고
- 팔리어는 대부분의 기기에 전용 음성이 없어 힌디어(hi-IN) 음성으로 대체 낭독합니다. 한문은 zh-CN 음성이 필요합니다.
- 페이지를 처음 열 때는 브라우저 정책상 소리가 자동 재생되지 않고, 경전을 한 번 클릭하면 재생됩니다.
- 추가한 경전은 기기·브라우저별로 저장되므로 백업은 `내보내기`를 사용하세요.
